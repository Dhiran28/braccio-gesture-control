# Glossary

| Term | Meaning |
|---|---|
| **Absolute angle** | link angle measured from horizontal (IK uses these) |
| **Anchor** | relative mode: the hand and gripper position remembered when following starts |
| **Candle pose** | all servos 90: arm straight up |
| **Callback** | a function the GUI calls when something happens (click, timer) |
| **Clamp** | force a value into a range (e.g. 15–165) |
| **Debounce** | ignore quick false changes; act only when a value persists |
| **Deprojection** | pixel + depth → 3D point in metres |
| **DHCP reservation** | router setting that always gives a device the same IP |
| **Extrinsics** | position/rotation between two sensors |
| **FK / IK** | forward / inverse kinematics: angles → position / position → angles |
| **FPS** | frames per second |
| **Intrinsics** | a camera's lens numbers (fx, fy, cx, cy) |
| **Landmark** | one of MediaPipe's 21 hand points |
| **Mocking** | replacing hardware with fake code for testing |
| **Offset** | degrees added to a servo value to fix assembly error/sag |
| **One Euro filter** | smoothing that adapts to speed |
| **Pipeline** | RealSense object delivering camera frames |
| **Process / thread** | a separate running program / a parallel path inside one program |
| **Queue** | thread-safe mailbox between threads |
| **RANSAC** | fit a model by random sampling and voting; robust to outliers |
| **Relative angle** | joint angle measured from the previous link (servos use these) |
| **RSUSB** | librealsense mode that talks to the camera via libusb (no kernel patches) |
| **Signal (SIGINT/SIGTERM)** | message from the OS to a process: Ctrl+C / terminate |
| **Tkinter** | Python's built-in GUI library |
| **UDP** | fast, connectionless network messages |
| **venv** | private Python environment for one project |
| **Workspace** | the region the gripper can actually reach |
